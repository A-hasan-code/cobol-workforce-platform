# Vision

## One line
Make every developer a COBOL-capable engineer — without rewriting bank COBOL systems.

## Promise
COBOL stays the runtime. We add a modern work layer so the world can:

1. **Understand** — plain English / modern view of legacy programs  
2. **Navigate** — impact maps (what breaks if this field changes)  
3. **Change safely** — suggested edits + tests + risk score  
4. **Prove** — local run, CI gates, auditor-friendly change reports  
5. **Observe** — health, slowdowns, blast radius, rollback signals  

## Positioning

| Say this | Not this |
|----------|----------|
| Control plane / workforce layer for COBOL estates | Yet another AI chat for COBOL |
| Bridge for global developers onto bank systems | Replace the mainframe OS on Day 1 |
| Local → CI → staging → prod like modern stacks | Pure nostalgia branding |
