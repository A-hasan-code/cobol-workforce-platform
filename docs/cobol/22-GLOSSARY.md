# Glossary

| Term | Meaning |
|------|---------|
| **Abend** | Abnormal end of a job/task |
| **Area A / B** | Fixed-format column regions |
| **Assign name / DD name** | Bridge between COBOL SELECT and external file |
| **Batch** | Non-interactive scheduled jobs (JCL) |
| **Bind** | Db2 step attaching package/plan |
| **Blast radius** | Set of programs/jobs affected by a change/failure |
| **CICS** | Customer Information Control System — online TX monitor |
| **COMMAREA** | Classic CICS inter-program data area |
| **Compilation group** | Source unit(s) compiled together |
| **Copybook** | Shared source text inserted via COPY |
| **DBRM / package** | Db2 precompile artifacts |
| **Dialect** | Compiler behavior profile (IBM/MF/gnu std) |
| **Division** | IDENTIFICATION / ENVIRONMENT / DATA / PROCEDURE |
| **EBCDIC** | Mainframe character encoding |
| **EIB** | CICS Execute Interface Block |
| **Elementary item** | Data item with PIC (leaf) |
| **Estate** | Whole set of programs, jobs, copybooks, data |
| **FD** | File description in FILE SECTION |
| **FILE STATUS** | 2-char status after file ops |
| **GDG** | Generation Data Group — versioned datasets |
| **Group item** | Data item with subordinate levels |
| **Host variable** | COBOL var used inside EXEC SQL |
| **JCL** | Job Control Language |
| **KSDS / ESDS / RRDS** | VSAM cluster types |
| **LE** | Language Environment (z/OS runtime) |
| **LINKAGE** | Section for passed parameters |
| **Load module** | Executable bound program on z/OS |
| **Mainframe** | z/OS-class central system |
| **OCCURS** | Table/array in data description |
| **Paragraph** | Named PROCEDURE block |
| **PIC / PICTURE** | Digits/chars/edit pattern |
| **QSAM** | Sequential access method |
| **REDEFINES** | Overlay storage views |
| **Run unit** | Executing set of programs |
| **Section** | Named group of paragraphs / DATA sections |
| **SQLCODE / SQLSTATE** | SQL result codes |
| **VSAM** | Virtual Storage Access Method |
| **Working-Storage** | Program-duration variables |
| **88-level** | Condition name on values |
